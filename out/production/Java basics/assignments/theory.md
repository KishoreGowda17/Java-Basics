1. Is JVM platform independent?
   ans : Yes, the JVM (Java Virtual Machine) is platform independent in the sense that the same Java bytecode can run on any operating system

2. Difference between JDK, JRE and JVM?
   JDK is used to develop Java applications, JRE is used to run Java applications, and JVM is responsible for executing Java bytecode. JDK contains JRE, and JRE contains JVM.

3) Why was JIT introduced?
   JIT was introduced to improve JVM performance. Instead of interpreting frequently executed bytecode repeatedly, the JIT compiler converts hot bytecode into native machine code at runtime, allowing it to execute much faster.

4) What is bytecode?
   Bytecode is the intermediate, platform-independent code generated by the Java compiler. It is stored in .class files and is executed by the JVM.Java is platform independent because its bytecode is platform independent, while the JVM is platform dependent.

5) Why is bytecode verified?
   Bytecode is verified to ensure that it is structurally valid, type-safe, and follows JVM rules before execution. This helps prevent invalid or potentially unsafe bytecode from being executed.

6) Difference between Heap and Stack?
   The heap is the JVM memory area used primarily for dynamically allocated objects and arrays and is shared between threads. The stack is per-thread and contains stack frames used for method execution, including local variables and references. Heap memory is managed largely by garbage collection, while stack frames are created and removed as methods are called and return.
   Heap = Objects
   Stack = Method calls

7) Where are instance variables stored?
   Instance variables are stored inside the object, and objects are allocated in the heap. Therefore, instance variables are generally said to be stored in the heap.

8) Where are local variables stored?
   Local variables are stored in stack

9) Where are String literals stored?
String literals are stored in the String Pool, which is part of heap memory in modern JVMs. The String Pool allows identical string literals to be reused, saving memory.

10) Why is type promotion needed?
Type promotion is used to safely perform operations involving different or smaller data types. In Java, types such as byte, short, and char are generally promoted to int during arithmetic, which helps avoid intermediate overflow and provides consistent expression evaluation.
